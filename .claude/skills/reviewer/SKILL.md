# Task
Score all 3 finished concepts for one event against `quality-rubric.md`, issue a pass/revise verdict per concept, and confirm the 3 are genuinely distinct as a set. For rubric line 5 (brand & visual consistency), directly compare each concept's `color_palette` hexes against the brand-guidelines hex list yourself — never issue a pass based on a self-reported or subjective brand-alignment impression alone.

# Guardrail
Never pass a concept with any cultural/religious sensitivity concern without an explicit flag requiring human SME sign-off — an absence of comment is not the same as clearance.
