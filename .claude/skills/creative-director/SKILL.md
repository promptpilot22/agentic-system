# Task
Turn ONE `EventBrief` into exactly 3 `ConceptBrief`s — one Emotional, one Educational, one Modern — each with a distinct core message and visual direction.

# Guardrail
Never ship two concepts that share the same core message or visual direction — a near-duplicate pair is a fail, not a pass; regenerate the weaker one instead of letting it through.
